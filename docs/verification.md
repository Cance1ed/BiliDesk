## 0.6.1 默认启动自动播放

日期：2026-11-10。环境：Windows 11 x64，Node.js 24.15.0，Electron 45.2.3。

- 新增默认开启的 `autoPlayOnLaunch`，旧配置缺少该字段时也默认开启；显式关闭可保存并恢复。「开机启动」仍独立且默认关闭。
- 应用完成本地数据及凭据恢复、窗口和电源事件注册后，仅自动播放一次当前列表的第一个视频。初始化过程中手动停止、播放、切换列表优先；空列表不创建壁纸窗口。开关不触发系统登录项变更。
- 48 项离线测试、生产构建及 Windows NSIS 打包通过。新增默认值 / 迁移 / 类型校验和持久化检查。
- 最终安装包通过 `--packaged --startup=enabled`：载入缺少新字段的旧配置后，无需手动调用播放，视频推进至 2.1741 秒 / 35 帧，且播放的是当前列表第一项。`--startup=disabled` 和 `--startup=empty` 均保持停止，未创建壁纸窗口。
- 最终安装包通过 `--packaged --subscriptions --playback --portrait`：公开订阅导入 28 个；真实视频推进至 2.0652 秒 / 34 帧；客户区完整覆盖 2560×1440。三联像素一致、四联、关闭、暂停恢复及横屏回退通过。
- CUA 原生窗口验证「启动后自动播放」默认开启，可切换关闭，磁盘配置确认保存为 false；恢复开启后截图见 `docs/screenshot-autoplay-windows.png`。测试使用独立数据目录，未操作个人账号收藏夹；未发现空白页或应用控制台错误。
- Mac 0.6.1 尚未构建或实机验证；已有 Mac 0.6.0 附件保持原样，不包含自动播放功能。安装向导全流程、Windows 10、多屏混合 DPI、真实账号登录与收藏写入仍未覆盖。
