# 设计与素材

使用内置 Image Gen 生成设计参考和独立素材，没有调用 CLI / API 密钥。

## 设计参考

文件：`docs/design-concept.png`。概念尺寸 1488×1058。

提示词：完整中文 BiliDesk 桌面应用，Windows / macOS 动态壁纸管理。白色主画布、冷灰侧栏、珊瑚粉 #ef6383、深灰中文无衬线字。左侧「我的壁纸 / 收藏夹 / 播放设置」及访客登录；主区标题「我的壁纸」「让喜欢的视频，成为桌面的风景」，添加按钮、阿尔卑斯草甸示意预览、右侧屏幕/模式/音量/启用控制、链接输入、空播放列表和访问权限脚注。禁止伪造视频和指标，全部控件可用 HTML/CSS 实现。

## 独立素材

文件：`public/alpine.png`。

提示词：16:9 自然摄影风格，夏日阳光下的绿色阿尔卑斯高山草甸，远处雪峰、蓝天与两朵小白云、前景白色野花及松林。平静、明亮、轻微胶片质感。满幅风景，没有文字、水印、标志、界面或边框。作为桌面壁纸管理器明确标注的空状态示意图。

应用标志是原创的简单显示器和播放三角 SVG，源文件 `public/icon.svg`，通过 `scripts/icons.mjs` 转为 PNG/ICO。UI 图标来自 lucide-react。
