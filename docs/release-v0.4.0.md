## 中文

BiliDesk 首个公开预览版：将 Bilibili 视频设为动态壁纸。

- 匿名链接 / BV / av / 分 P 播放，轮播与点播。
- 扫码登录、收藏夹导入、指定用户收藏夹定时订阅。
- 订阅合集的整合集或跨页勾选导入。
- 可选播放列表到账号收藏夹的追加同步。
- 竖屏自动三联 / N 联、手动 2～8 联，单视频解码及同步声音。
- 修复 Windows 原生边框导致的露缝。
- 中英双语文档、Apache-2.0 许可证及第三方许可声明。

**下载**：`BiliDesk-0.4.0-win-x64.exe`，使用 `SHA256SUMS.txt` 核对校验和。升级前从托盘退出旧版。

**验证**：36 项离线测试通过；Windows 11 x64 实测播放、2560×1440 完整覆盖、联屏像素一致及暂停恢复；公开收藏夹 / 合集接口已测试。

**预览版限制**：安装包未签名；macOS 尚未真机验证，未附 Mac 包；真实账号扫码确认、私有 / VIP 内容及收藏写入仍需账号验收。模拟写入测试不等于真实账号全流程验证，接口可用性取决于 Bilibili。

## English

The first public preview of BiliDesk: Bilibili videos as live desktop wallpapers.

- Anonymous URLs / BV / av IDs / multipart playback, playlists and on-demand selection.
- QR login, favorite imports, scheduled subscriptions to specific user folders.
- Whole-collection or cross-page selected-video imports.
- Optional additive synchronization to an account-owned favorite folder.
- Automatic portrait tiling or fixed 2–8 columns sharing one decoded video and audio track.
- Windows native-border gap fix.
- English / Chinese documentation, Apache-2.0 licensing, and third-party notices.

**Download**: `BiliDesk-0.4.0-win-x64.exe`; verify with `SHA256SUMS.txt`. Exit the previous version from the tray before upgrading.

**Validation**: 36 offline tests pass. Windows 11 x64 playback, complete 2560×1440 coverage, identical tiled pixels, and pause/resume tested. Public favorite-folder and collection endpoints checked.

**Preview limitations**: unsigned installer; macOS not tested on hardware and no Mac artifact attached. Real-account QR confirmation, private/VIP content, and favorite writes still require acceptance testing. Simulated writes do not establish real-account end-to-end success. API availability depends on Bilibili.
